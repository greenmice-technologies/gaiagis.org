## From a file to a map you can share {#overview}

Gaia GIS is a web map and chart workspace for data analysts. Start with your geographic data, shape it into a map, and explain what you found.

### Bring your data

Import geographic files or add layers from external map services.

### Build your map

Edit features and attributes, arrange layers, and choose how they look.

### Explain the results

Combine queries, maps, and charts in a notebook, then publish or export it.

[Explore the product](/en/product/)

## Get started with Gaia GIS {#get-started}

Gaia GIS is self-hosted: you install it on your own computer or servers and open it in your browser. The installation guide covers requirements, configuration, and setup.

**[Read the installation guide](/en/install/)** · [Browse the guides](/en/manuals/)

## A few practical questions {#faq}

### Do I need to install anything?

Yes, once. After that, everyone uses Gaia through a browser.

### Is there a hosted version?

No. You run Gaia yourself, and your data stays on your systems.

### Can I use existing geographic data?

Yes. Gaia imports common vector and raster formats and reads external WMS and WFS services.

### Can I keep a project private?

Yes. A workspace is private until you share it or make it public.

### Where can I find help?

Start with the [guides](/en/manuals/), or [contact us](mailto:info@gaiagis.org) for help with installation.
