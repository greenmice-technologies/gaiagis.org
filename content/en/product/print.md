## Make your map ready for the handover

A finished map needs enough context to stand on its own. Gaia GIS helps you turn a workspace into a sheet for a report, presentation, or printed reference, with the legend, scale, and explanation your audience needs.

## Build the page around the map

Start with the default layout or arrange your own in the layout editor. Add map frames, legends, scale bars, and north arrows, then complete the sheet with text, images, tables, charts, and shapes.

Keep the title, map, and supporting information together so the exported page remains understandable away from the editor.

## Choose PDF or GeoPDF

Export a PDF for sharing and printing, or choose GeoPDF to retain geographic information for use in compatible software. Set the export resolution to suit the intended output.

For a report that needs a longer written explanation, pair your map sheet with a [notebook](../notebook/) exported as HTML or PDF.

## Produce a set from one frozen edition

When a delivery includes several sheets, freeze a version of your data and layouts, then produce multiple prepared layouts in one run. The job uses those frozen inputs, keeping that delivery tied to the edition you selected even as work continues.

Use this workflow for a set of project maps, location sheets, or other deliverables that need to belong to the same edition.
