Gaia GIS is self-hosted. You install it on your computer or your organization's servers, then use it through your browser. There is no hosted version to sign up for, and your data stays on your systems.

In a terminal:

```bash
curl -fsSL https://gaiagis.org/install.sh | sh
```

The command clones the installer, asks for three secrets, and starts the stack. Press Enter to generate each secret.

Requirements, configuration, and the later steps are in the installation guide:

**[Open the installation guide on GitHub](https://github.com/greenmice-technologies/gaia)**

**Availability:** some application packages are not yet available for public download. Check the guide for current access requirements before starting.

A new installation has payments turned off, and accounts use the unlimited plan.

Once installed, you can change the application name, logo, and colors in Settings. The guide also covers configuration for access through your own web address.

[Contact us](mailto:info@gaiagis.org) if you need help with installation.
