### What can I use Gaia GIS for?

Use Gaia GIS to prepare geographic data, build and style maps, explain findings in a notebook, and produce pages or files for others to use. It is designed around the path from source data to a map, an analytical document, or a printed sheet. [Explore the product](/en/product/).

### Do I need to install software on every user's computer?

Gaia is installed on a computer or server; users then access that installation through a browser. Check requirements and package availability on the [installation page](/en/install/) before starting.

### Is there a hosted version?

No. Gaia is self-hosted. You or your organization operate the installation and manage the infrastructure, access, and stored data.

### Can I use existing geographic data?

Yes. Import formats such as GeoPackage, Shapefile, GeoJSON, KML, GPX, and GeoTIFF. CSV and Excel tables with latitude and longitude columns can become point layers. You can also consume external WMS and WFS services; Gaia does not publish those services itself.

### Do I need SQL to use Gaia?

You can import data, edit and style maps, write notebook text, and prepare print layouts through the interface. SQL is used for notebook query blocks when you want to explore data and show the results as tables, maps, or charts.

### Can I keep a project private?

Yes. A private workspace is accessible within its organization according to membership roles, with administrative access retained by instance administrators. It is not a personal workspace visible only to its creator. Public visibility alone does not publish a draft: a workspace must also be Published to be available publicly.

### Can someone review my work before I publish it?

Yes. You can create a preview link for a draft. Anyone with that link can access the preview, so share it only with the intended reviewers. Named revisions let you save milestones and restore an earlier version.

### What can I deliver to someone who does not use the editor?

Publish a public workspace page, export a notebook as HTML or PDF, or create a map sheet as PDF or GeoPDF. You can also export the map as GeoTIFF and the workspace data as GeoPackage. [Compare sharing and export options](/en/product/workspaces/).

### Who manages the data in an installation?

The person or organization operating it manages its accounts, workspaces, and stored files. Connections to external map or identity services depend on the configuration and services you choose. Administrators can point the application's legal and support links to their own pages in Settings.

### Is self-hosted the same as open source?

No. Gaia GIS is distributed for self-hosted installation; the application source code is not public. Check the installation guide for current package access requirements.

### Where can I find help?

Follow the [tutorials](/en/tutorials/) for a first workflow, consult the [guides](/en/manuals/) for individual tools, or [contact us](/en/contact/) about your use case or installation.
