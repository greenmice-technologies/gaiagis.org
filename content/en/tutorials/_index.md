Hands-on guides for every feature of the Gaia editor. Each tutorial lists what you need, walks through the steps with screenshots taken from the real application, and ends with a result you can check.

The tutorials share the same sample data, so you can follow them in order and build one map along the way:

| File | Content | Used for |
| --- | --- | --- |
| [natural_earth.gpkg](/downloads/tutorials/natural_earth.gpkg) | Natural Earth GeoPackage (EPSG:4326, 4.3 MB): `countries`, `coastlines`, `boundary_lines_land`, `disputed_areas`, `populated_places` | Vector layers, tables, styles, print |
| [precip30min.tif](/downloads/tutorials/precip30min.tif) | World precipitation grid (GeoTIFF, EPSG:4326, 720 × 360) | Raster layers |

## Tutorials

1. [Your first workspace](01-first-workspace.md) — create a workspace, choose a projection, and import a GeoPackage.
2. [Add and organize layers](02-layers.md) — base maps, empty layers, groups, grids, tile services, and layer order.
3. [Explore data with the attribute table](03-attribute-table.md) — filter, select, edit, and export the features of a layer.

For a description of each screen and its options, see the [Manuals](../manuals/_index.md).
