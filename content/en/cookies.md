## This website

gaiagis.org does not set analytics or advertising cookies. The pages are static files.

## A Gaia installation

The application stores a few values in the browser of the person using that installation. They stay in that browser. They are not sent to gaiagis.org.

- **Cookie notice.** When you choose Accept, the browser remembers that choice so the notice stays hidden.
- **Sign-in.** The sign-in token is kept for the browser session. If you tick Remember me, it remains after you close the browser. Signing out removes it.
- **Language.** The language you pick is kept for the session.
- **Editor.** The coordinate format, and a local copy of an unsaved print layout, can be kept in the browser.

The notice on the sign-in page is the one that links here, unless an administrator sets a different **Cookies** address in **Settings**.
