Open **Administration**, then **Application**, then **Settings**.

The page lists every setting with its type and a description. Use **Sort** to change the order.

## Identity and look

| Setting | What it changes |
| --- | --- |
| **Title** | The name shown in the top bar and in the browser tab |
| **Description** | The description search engines read |
| **Primary Color** | The main color of the interface |
| **Theme** | Light, dark, or following the operating system |
| **Preset** | The overall look: Aura, Lara, or Nora |
| **Surface** | The tone of backgrounds and panels |
| **Logo** | The logo in the top bar and on the sign-in pages |
| **Background** | The image behind the sign-in and account pages |
| **Background Repeat** | How that image tiles: repeat, no-repeat, repeat-x, or repeat-y |
| **Background Size** | auto, cover, or contain |
| **Background Position** | Where the image sits, for example center |
| **Layout Preferences** | Whether users may choose their own theme and colors |

For **Logo** and **Background**, use **Upload**, **Restore default**, or **Remove**.

## Sign-in

| Setting | What it changes |
| --- | --- |
| **Enable Signup** | Whether people can create their own account |
| **Enable Reset** | Whether people can ask for a password reset link |

## Pages

**Privacy Policy**, **Terms of Service**, **Cookies**, **Contact**, **About**, and **FAQ** are web addresses. Leave an address empty to hide that link. When you set one, the sign-in page and the footer open it in a new tab. The cookie notice links only to **Cookies**.

A new installation uses these addresses. **Restore default** puts an address back after you clear it.

| Setting | Default |
| --- | --- |
| **Privacy Policy** | https://gaiagis.org/en/privacy/ |
| **Terms of Service** | https://gaiagis.org/en/terms/ |
| **Cookies** | https://gaiagis.org/en/cookies/ |
| **Contact** | https://gaiagis.org/en/contact/ |
| **About** | https://gaiagis.org/en/about/ |
| **FAQ** | https://gaiagis.org/en/faq/ |
