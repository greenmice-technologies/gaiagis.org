The viewer shows a workspace as a reader sees it: the notebook and the map, without the editing tools. The app menu is hidden, as in the editor. The back arrow returns to the previous page.

The top bar is a single row, the same height as the editor bar. It shows the name of the workspace, with its status and visibility, and:

- **Copy published link** — when the workspace is published and public
- **Export** — save the notebook as HTML or PDF. **Open Geospatial PDF** is in the same menu when a geospatial PDF has been saved
- **Open editor** — switch to the [editor](workspace-editor.md), if you are allowed to edit

Use **+** and **–** on the map to zoom.
