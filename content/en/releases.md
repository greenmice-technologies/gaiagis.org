Gaia GIS uses semantic version numbers, such as `1.4.0`. Only major releases also get a name, taken from the Titans, the children of Gaia in Greek myth. A minor release is quoted with its major: "Gaia GIS 1.2 (Oceanus)".

Each major has its own primary color, which is also the default color of the application for that release.

| Version | Name | Color |
| --- | --- | --- |
| 1.0 | Oceanus | `#0B5D8E` |
| 2.0 | Themis | `#6D4AA8` |
| 3.0 | Hyperion | `#E8590C` |
| 4.0 | Iapetus | `#8B5A3C` |
| 5.0 | Theia | `#D99A00` |
| 6.0 | Coeus | `#3949AB` |
| 7.0 | Tethys | `#1B9AAA` |
| 8.0 | Mnemosyne | `#8E2C5A` |
| 9.0 | Phoebe | `#7C8FB0` |
| 10.0 | Rhea | `#3C8D40` |
| 11.0 | Crius | `#B3261E` |
| 12.0 | Cronus | `#2D2A32` |

Names are fixed once a major is released; later themes may still change order until then.

## 1.0 Oceanus

The river that encircles the world: origin and boundary. Its sign-in background is a set of concentric rings, like waves or isobaths.
